
# 🩺 NeuroSpark – Blood Vessel Blockage Detection

## 📌 Project Overview

**NeuroSpark** is an innovative **non-invasive blood vessel blockage detection system** that uses **Doppler Ultrasound Imaging** enhanced with **AI-powered analysis**. It is designed to provide an affordable, radiation-free, and portable alternative to conventional angiography, making vascular diagnostics accessible in both hospitals and rural healthcare centers.

---

## 🚀 Problem Statement

* Conventional **angiography** is invasive, expensive, and exposes patients to **radiation** and **contrast agents**.
* There is a critical need for a **safer, cost-effective, and portable solution** for detecting vascular blockages.

---

## 💡 Proposed Solution

Our system leverages **Doppler Ultrasound** with **multi-modal imaging** (Color, Power, Spectral Doppler, Elastography) combined with **AI/ML models** for accurate detection and classification of blood vessel blockages.

---

## 🛠 Features

* ✅ **Multi-Modal Doppler Imaging**: Color, Power, Spectral, and Elastography
* ✅ **AI Integration**: Machine learning (TensorFlow, PyTorch) for blockage detection & classification
* ✅ **Real-Time Visualization**: 2D/3D reconstruction of vessels (OpenCV, VTK)
* ✅ **Portable Hardware**: Handheld probe + compact processing unit with touchscreen interface
* ✅ **Radiation-Free**: No contrast agents or ionizing radiation
* ✅ **Affordable Diagnostics**: ₹2,000–5,000 per scan vs ₹25,000–50,000 for angiography

---

## 🔬 Technical Stack

**Hardware:**

* High-frequency ultrasound transducer (5–15 MHz)
* Portable processing unit
* Medical-grade display

**Software:**

* **Signal Processing**: Python (NumPy, SciPy)
* **Image Processing**: OpenCV, PyTorch
* **AI/ML Models**: TensorFlow
* **Visualization**: VTK (3D reconstruction)
* **UI/UX**: Flutter (cross-platform)
* **Database**: DICOM-compatible storage
